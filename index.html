Módulo 1: Infraestrutura de Redes

Este módulo sintetiza as competências do ciclo completo de TI, desde a concepção física da rede até a administração de sistemas. O foco é garantir comunicação de dados segura, estável e escalável.

Síntese Acadêmica

Este conteúdo consolida o aprendizado técnico sobre o ciclo de vida de uma rede local. Competências desenvolvidas em três pilares fundamentais:

  • Infraestrutura Física: Montagem de ativos, organização de racks e certificação de pontos de rede.
  • Continuidade e Manutenção: Implementação de rotinas preventivas e corretivas para assegurar a alta disponibilidade.
  • Administração Lógica: Instalação e configuração de NOS e serviços essenciais (DNS, DHCP, AD) aliados a monitoramento real.
UC5: Instalação de Redes Locais

Este processo consiste no levantamento técnico do ambiente para definir a melhor topologia e o posicionamento dos equipamentos. A execução envolve a passagem de cabos, montagem de conectores e racks, garantindo suporte de tráfego sem interferências.

  • Planejamento Físico: Estudo de topologias e instalação de ativos de rede (switches/roteadores).
  • Manutenção: Estratégias para identificar falhas e otimizar performance.
  • Sistemas Operacionais (NOS): Instalação de ambientes focados em serviços essenciais.
  • Monitoramento: Uso de ferramentas para acompanhar a saúde de servidores.
UC6: Manutenção de Redes Locais

O planejamento utiliza normas de cabeamento estruturado para criar um projeto escalável. A execução foca na identificação correta para permitir que qualquer técnico entenda a estrutura rapidamente.

  • Infraestrutura e Topologias: Planejamento e configuração física de ativos para integridade.
  • Continuidade de Negócio: Aplicação de rotinas preventivas para evitar paradas (manutenções ágeis).
  • Administração (NOS): Domínio na instalação para serviços como DNS, DHCP e diretórios.
  • Gestão de Saúde: Ferramentas de análise em tempo real para incidentes e vulnerabilidades.

Resumo: Redes

As redes de computadores interligam dispositivos globalmente. Compreender redes envolve entender roteadores, switches, cabeamentos (como o par trançado RJ-45) e os protocolos TCP/IP que garantem a comunicação da internet.

Módulo 2: Ubuntu

Conheça o Ubuntu, uma das distribuições Linux mais utilizadas no mundo. Ele é amplamente usado em estudos, servidores e ambientes profissionais devido à sua estabilidade, segurança e facilidade de utilização.

Administração e Terminal Ubuntu

O Ubuntu permite administrar sistemas por meio da interface gráfica ou do terminal. O uso de comandos é fundamental para instalação de programas, gerenciamento de arquivos e configuração de serviços.

  • Terminal: Execução de comandos e gerenciamento do sistema.
  • Pacotes: Instalação e atualização de programas através do apt.
  • Usuários e Permissões: Controle de acessos e segurança.
  • Ferramentas de Rede: Diagnóstico e testes de conectividade.

Resumo: Ubuntu

O Ubuntu é uma distribuição Linux bastante utilizada em servidores e ambientes corporativos. Ele oferece estabilidade, segurança e uma poderosa linha de comando para administração de sistemas.

Módulo 3: Windows Server

Aprenda os principais recursos do Windows Server, sistema operacional utilizado em empresas para gerenciar usuários, computadores, arquivos e serviços de rede.

Administração com Windows Server

O Windows Server permite centralizar a administração da infraestrutura de rede e dos recursos corporativos.

  • Active Directory: Gerenciamento de usuários e computadores.
  • DNS: Conversão de nomes em endereços IP.
  • DHCP: Distribuição automática de endereços IP.
  • Compartilhamentos: Controle de acesso a arquivos e pastas da rede.

Resumo: Windows Server

O Windows Server é amplamente utilizado em ambientes corporativos para administrar usuários, permissões, compartilhamentos e serviços essenciais como Active Directory, DNS e DHCP.
